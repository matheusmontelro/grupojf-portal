# Security Policy

## Segredos

Nao versionar tokens, `.env`, chaves privadas, dumps de banco, relatorios com dados sensiveis ou logs de producao. Use GitHub Secrets/Environments para automacoes.

## Reporte

Reporte vulnerabilidades diretamente aos mantenedores do repositorio. Evite abrir issues publicas com segredos, dados pessoais ou detalhes exploraveis.
